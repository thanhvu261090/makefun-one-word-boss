One word for the boss: the one who is never there when you need them, and only materialises to haunt you at review time.

> "Ghostboss"

## How it works

`main.py` holds the entry word as a constant, checks it against the kit's gate (UTF-8 text, 1–30 characters, not only whitespace, a single word with no spaces or control characters), and writes it to `/output/entry.txt` when run with `python3 main.py`.
